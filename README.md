# SQL-кейсы аналитика

Практические SQL-кейсы по контролю качества данных, коммерческой аналитике и анализу бизнес-показателей.

Репозиторий содержит несколько законченных задач, приближенных к типовым рабочим сценариям аналитика.

Основной акцент сделан не на демонстрации отдельных SQL-конструкций, а на подготовке данных, проверке бизнес-правил и получении готового аналитического результата.

## Кейсы

### 1. Сверка заказов между ERP и CRM

Контроль качества обмена данными между двумя информационными системами:

- определение актуальной версии заказа;
- поиск отсутствующих записей;
- проверка соответствия клиентов;
- контроль расхождений сумм;
- обработка исключений.
