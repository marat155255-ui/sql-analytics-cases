# SQL Analytics Cases

Практические SQL-кейсы по контролю качества данных, коммерческой аналитике и анализу бизнес-показателей.

Репозиторий содержит несколько законченных задач, приближенных к типовым рабочим сценариям аналитика. Основной акцент — не на отдельных SQL-конструкциях, а на подготовке данных и решении бизнес-задачи.

## Кейсы

### 1. ERP ↔ CRM Reconciliation

Сверка заказов между двумя информационными системами:

- определение актуальной версии записи;
- поиск отсутствующих заказов;
- проверка клиента;
- контроль расхождения сумм;
- обработка исключений.
